# Capacitance Scale
This software is specific to the technical requirements of maintaining a set of capacitors in calibration using a 10:1 capacitance ratio bridge.
The technical process is described in MSL.T.E.005.04.
The overall process is described in the Sphinx generated index.html in the /build/html file.

There is an intent to develop a GUI input to allow direct input of manual readings from the ratio bridge. The large number of csv files work well for managing input and output data, but this could be automated and streamlined as part of the GUI development.

Further changes will be made when following a significant refurbishment of the equipment and the introduction of some new reference standards.
